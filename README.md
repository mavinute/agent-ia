# Agente de IA para Consultório Odontológico #


O agente vai orientar dentistas passo a passo com base nas informações enviadas pela aplicação. Essencialmente um assistente clínico inteligente.

### Resumo do Agente: ###
Dentista preenche um formulário com dados do paciente/caso
O agente processa e retorna protocolo de procedimento + prescrição de medicamentos
Sem memória — cada consulta é independente
Stack: Fastify + Zod + OpenAI + CORS
